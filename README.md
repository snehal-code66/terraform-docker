Task 3 – Provision Local Docker Container Using Terraform
Objective

To provision and manage a local Docker container using Terraform.

Tools Used

Terraform

Docker

Files

main.tf

README.md

Steps Performed

Configured the Docker provider in Terraform.

Defined a Docker image and container in main.tf.

Initialized Terraform.

Validated and planned the configuration.

Created the Docker container using Terraform.

Verified the running container using Docker.

Destroyed the container after completion.

Terraform Commands Used
terraform init
terraform validate
terraform plan
terraform apply
terraform show
terraform destroy

Result

Successfully provisioned a local Docker container using Terraform and verified its execution.
